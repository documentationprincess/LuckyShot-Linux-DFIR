- [ ] Open LuckyShot inside Hack The Box and confirm its status is **Retired**.
- [ ] Do not treat **Expired** as permission to publish.
- [ ] If it is Active, keep this repository private and use only the spoiler-light LinkedIn post.

- [Streaming / Writeups / Walkthrough Guidelines](https://help.hackthebox.com/en/articles/5188925-streaming-writeups-walkthrough-guidelines)
