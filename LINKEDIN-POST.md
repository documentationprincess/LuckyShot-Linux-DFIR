# LinkedIn Post

I completed LuckyShot, a Linux DFIR Sherlock on Hack The Box, and turned the investigation into a structured portfolio case study.

The most useful part was not simply finding answers. It was changing my assessment when stronger evidence appeared: ruling out an early hypothesis, moving from summarized login records to authentication logs for timestamp accuracy, correlating shell history with persistence artifacts, and checking whether an apparent scheduled task actually executed.

This project strengthened my experience with:

- Linux authentication and system-log analysis
- Timeline reconstruction and evidence correlation
- Credential-access and persistence artifacts
- MITRE ATT&CK mapping
- Clear incident documentation

I packaged the work as a concise README with the detailed commands, evidence trail, ATT&CK mapping, and follow-up learning kept in separate documentation.
